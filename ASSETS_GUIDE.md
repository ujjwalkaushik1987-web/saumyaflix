# SAUMYAFLIX — Personal Asset Replacement Guide 📸🎬🎵

This guide lists every single photo, audio, and video asset used in SAUMYAFLIX, including the exact filename, location, purpose, and recommended dimensions.

---

## 📂 Directory Layout

All personal media files are stored inside the `public/` directory:

```text
public/
├── images/
│   ├── hero/            # Hero section banner photo
│   ├── memories/        # Memory cards for the 5 Netflix rows
│   ├── gallery/         # Dedicated photo memory gallery
│   ├── timeline/        # "The Story of Us" milestone photos
│   └── fallbacks/       # Automatic high-res romantic fallbacks (already included)
├── videos/              # Birthday video trailer
└── music/               # Background romantic soundtrack
```

## 🛡️ Built-In Graceful Fallbacks

If you don't have all photos ready immediately, don't worry:
- Every image component has an automatic fallback to high-resolution romantic SVG badges in `public/images/fallbacks/`.
- If an image file is missing, the card will never show a broken image icon.
- Background audio already has a working ambient melody (`public/music/background.mp3`) with an in-browser Web Audio romantic chord synthesizer fallback.
- The birthday video trailer includes a romantic scene montage slideshow fallback if `birthday-trailer.mp4` is not yet supplied.
