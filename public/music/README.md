# 🎵 Background Music Storage Directory

Place your favorite romantic MP3 or audio track here!

For example:
- `romantic-melody.mp3`
- `our-song.mp3`

Then verify the path in `src/data/config.js`:
```javascript
musicFile: "/music/romantic-melody.mp3"
```

*Note: Even without an audio file here, SAUMYAFLIX includes a built-in romantic ambient chime synthesizer, so music will play right away!*
