# 🎬 Birthday Trailer Video Directory

Place your personal birthday video or video montage here!

Expected default file:
- `trailer.mp4`

Then verify the path in `src/data/config.js`:
```javascript
videoFile: "/videos/trailer.mp4"
```

*Note: If no video file is placed here yet, the video player automatically displays a cinematic montage preview with romantic quotes and scene transitions!*
