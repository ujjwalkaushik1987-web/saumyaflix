# 📸 Photo Storage Directory

Place Saumya's personal photographs in this folder!

For example:
- `photo1.jpg`
- `photo2.jpg`
- `smile.png`

Then update `src/data/config.js` to reference:
```javascript
image: "/images/photo1.jpg"
```
Or you can keep using the curated aesthetic high-resolution photos already loaded in `config.js`!
